If the Live Server Is Down (Three Fallback Tiers)

        

          ClosedLoop operates across three progressive verification tiers to ensure offline reproducibility:
        

        

          

            Tier 2: Live Backend
            
Streams real-time simulation episodes over Server-Sent Events when local dev server runs.

          

          

            Tier L: Local Simulator
            
Run locally in terminal via make playground-local for physical stepping.

          

          

            Tier 0: Offline Mode
            
Static browser mode verified against precomputed episodes and hash trees with zero server needed.
